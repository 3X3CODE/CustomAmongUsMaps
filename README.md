## Setting up the Environment
1. Install the [.NET SDK](https://dotnet.microsoft.com/en-us/download).
2. Install an IDE like Jetbrains Rider, VS Code or Visual Stdio (This tutorial is made with Jetbrains Rider in mind).
3. Install the [Unity Editor (2022.3.44f1)](https://unity.com/releases/editor/whats-new/2022.3.44f1#notes).

### Jetbrains Rider setup
- After installing and opening Rider for the first time, it may ask for a license which you can pick a license you prefer.
- Create a new Class Library project using net 6.0 from SDK 6.0 (install the .NET SDK if you haven't).
### Unity Project setup
- Create a new **BRP(Built in Render Pipeline) 3D project** through the editor or Unity Hub if you have it installed. (ensure your editor version is **v2022.3.44f1**).
